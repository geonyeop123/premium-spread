## 수용기준

| # | 수용기준 (관찰 가능) | 근거 | 출처 | 티어 | 검증 수단 | 검증 명령 | 통과 조건 |
|---|---|---|---|---|---|---|---|
| AC1 | | | `요구` | T1 | `기존` `./gradlew architectureTest` | | exit 0 |
| AC2 | | | `리뷰` | | `신규테스트` `io.x.FooTest` | | |
| AC3 | | | `추론` | | `신규스크립트` `scripts/check-foo.sh` | | |

**`출처`** — `요구`(사용자 요구 원문) / `상위`(상위 동결 문서의 ID) /
`리뷰`(리뷰에서 파생) / `추론`(근거 없음).
`리뷰`와 `추론`은 Gate 1에서 같은 무게로 검토한다.

**`검증 수단`** — 종류 + 식별자. 식별자를 못 적으면 T1도 T2도 아니다.
Gate 1에서 셋 중 무엇을 만들지 사람에게 묻는다. 티어를 낮추는 것이 아니다.

**`검증 명령`** — 이름 붙은 산출물 하나를 부르는 단일 명령.
`|` `&&` `;` `!` `$(` 가 있으면 T1이 아니다.
