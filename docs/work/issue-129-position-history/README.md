# 실계정 포지션 기록과 매분 관측 이력 저장 (issue #129)

실계정 모니터가 포지션 한 건(수량 0 → 다시 0)과 그 안의 사건, 매분 관측(보유 중 `HOLDING`·포지션 없을 때 `FLAT`)을
V24 신규 테이블 3개에 쌓는다. 기존 알림·`account_pnl_latest`·모니터 상태는 바뀌지 않는다.
