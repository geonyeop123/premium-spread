def trade_ret(i, j):
    """i 일에 진입, j 일에 청산 시 Long KR + Short Binance 선물 gross 수익률(%, 한국 진입 금액 대비)."""
    a, b = day.iloc[i], day.iloc[j]
    kpnl = b.kr - a.kr
    fpnl = (a.fu - b.fu) * b.fx
    fund_pct = (b.cumf - a.cumf) * a.fu * a.fx / a.kr   # 해외 명목가 대비 펀딩을 한국 진입금액 대비로 환산
    return (kpnl + fpnl) / a.kr * 100, fund_pct * 100

def fx_term(i, j):
    """gross 중 환율 노출 성분: F0*(FX1-FX0)/K0. 이 구조는 BTC 중립이지만 USD/KRW Long 이다."""
    a, b = day.iloc[i], day.iloc[j]
    return a.fu * (b.fx - a.fx) / a.kr * 100

6권장 조치

  1. 지금은 신규 진입하지 않는다. 보유 중이면 청산한다. 현재 1.99%는 A의 청산선(-0.20%)과 B의 청산선(1.61%)보다 모두 위다. 근거: F1·F2 · 바로 실행 가능
  2. 전략 A를 기본으로 한다: 김프가 직전 180일 P30(현재 -0.93%) 아래로 내려오면 한국 현물 매수 + Binance 선물 Short 같은 수량. 180일 P50(현재 -0.20%) 이상이면 청산, 120일이 지나면 무조건 청산. 기준선은 매주 다시 계산한다. 조건: 왕복 비용 0.4%p 이하(Bithumb 수수료 쿠폰·지정가, Binance 지정가). 비용이 0.8%p를 넘으면 B(90일 P20 → P90, 60일)로 바꾼다 · 근거: F6·F7
  3. 선물 Short는 1배로 잡고, BTC +20%마다 증거금을 보충하거나 양쪽을 줄이는 규칙을 미리 정한다. 근거: F4 — 보유 중 BTC 최대 +66% · 자본 대비 기대 수익은 1배 기준 연 약 4.7~5.3% (펀딩 현재 수준~검증 구간 수준)
  4. 환율 노출을 인정하거나 헤지한다. 헤지하려면 한국 진입금만큼 USD/KRW Short(예: KRX 미국달러선물)가 필요하다. 헤지하지 않으면 "김프 목표 도달 = 이익"이 아님을 기록에 남기고, 환율이 직전 1~3일 1% 넘게 움직였으면 진입을 하루 미룬다. 근거: F3 · 달러선물은 별도 계좌·예탁금 필요 추정 — 이번 분석에서 확인하지 않음
  5. 앱 알림으로 감시한다. premium-spread의 임계값 알림에 A의 진입선·청산선을 걸고 주 1회 갱신한다. 펀딩비(최근 30일 합 0.59%)가 연 2% 아래로 떨어지면 기대값을 다시 계산한다. 기준선 자동 갱신(이동 분위수 알림)은 앱에 없는 기능이라 넣으려면 별도 작업(orchestrator) 필요
