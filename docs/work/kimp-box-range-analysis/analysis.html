결론 "김프는 평균으로 돌아온다"는 맞다 (정상 시계열, 반감기 약 12.5일). 하지만 "고정된 박스"는 아니다 — 과거 90일로 그린 박스에 다음 30일이 머문 비율은 72% (기대 90%)이고, 박스 유지 여부는 환율 안정과 거의 무관하다 (상관 -0.05). 이론은 "움직이는 박스 + 평균회귀"로 고쳐야 데이터와 맞는다.

1요약

이 리포트의 심각도는 코드 결함이 아니라 가설에 대한 판정 강도다 — 높음: 가설의 핵심 주장을 반증, 보통: 조건부 반증·실전 주의, 정보: 가설을 지지하는 사실 또는 데이터 범위 기록.

지지: 2019-09~2026-11 일별 김프(Bithumb vs Binance 선물, n=2,626)는 ADF p=0.0001, KPSS p=0.076로 정상 시계열이다. 중앙값 1.09%, P5~P95 = -1.55% ~ 5.70%.

반증: 박스의 위치와 폭이 체제마다 바뀐다. 연평균이 2020년 −0.55% → 2021년 3.68% → 2026년 0.10%로 움직였고, 표본 외 박스 체류율은 어떤 창 길이에서도 90%에 못 미친다(58~81%).

환율 조건: 환율이 오르면 김프는 즉시 내려간다(1% 상승당 시간 단위 -0.70%p, 일 단위 -0.43%p). 하지만 이 효과가 김프 변동에서 차지하는 몫은 8% 안팎이다. 환율이 고정되어도 박스가 깨지는 주원인(코인 수요 쇼크)은 그대로 남는다.

def backtest(x, N=90, lo=.1, hi=.9, cost=0.3, timeout=60):
    trades, i = [], N
    while i < len(x):
        past = x.iloc[i - N:i]
        if x.iloc[i] < past.quantile(lo):
            tgt = past.quantile(hi); j = i + 1
            while j < len(x) and j - i <= timeout and x.iloc[j] < tgt: j += 1
            j = min(j, len(x) - 1)
            trades.append((x.index[i], x.index[j], x.iloc[i], x.iloc[j], (j - i), x.iloc[j] >= tgt))

6권장 조치

  1. 가설을 "고정 박스"에서 "이동 박스 + 평균회귀"로 바꾼다. 기준은 직전 90~180일 분위수로 매일 다시 계산하고, 중심값에서의 괴리를 반감기(약 12일)로 해석한다. 영향 범위: 매매 판단 기준 · 단독 수정 가능: 예 — 코드 변경 없이 분석 기준만 바꾸면 된다
  2. 환율 점프 직후 신호는 거른다. 직전 1~24시간 환율 변동이 1%를 넘으면 김프 신호를 보류하거나, β로 보정한 김프(P − β·ΔFX)를 함께 본다. 영향 범위: 알림·진입 신호 · 단독 수정 가능: 예 — 다만 앱 알림에 넣으려면 별도 설계(orchestrator) 필요
  3. 체제 전환 감지를 먼저 둔다. 박스 이탈이 폭의 1배를 넘으면(이번 표본에서 90→30일 창의 11%) 그 박스를 버리고 새 분포가 쌓일 때까지 쉰다. 영향 범위: 손실 꼬리(F2·F5) · 단독 수정 가능: 예
  4. 비용 포함 재검증. Binance 펀딩비 이력(/fapi/v1/fundingRate, 공개)과 실제 수수료를 넣어 F5 백테스트를 다시 돌리고, 파라미터는 2019~2022로 고른 뒤 2023~2026에서만 평가한다. 영향 범위: F5 결론의 신뢰도 · 단독 수정 가능: 예 — analyze.py에 펀딩비 수집만 추가

확인하지 못한 것 · 가정

  • USDT = USD 가정 — 앱과 같다. USDT 디페그(대부분 ±0.5% 이내)가 김프에 그대로 섞인다.
  • 2020-01 이전 환율은 일봉 — 종가 시각을 21:00 UTC로 가정하고 forward-fill했다. 2019-09~2020-01 주 시계열 약 140일의 환율 오차는 ±0.5% 수준으로 추정한다 추정.
  • 주말·휴장 — 외환 시장이 닫힌 동안 환율은 마지막 값이다. 일 시계열은 72시간 이내 값만, 회귀는 1시간 이내 값만 썼다.
  • Twelve Data 오염 값 — 2024-01-02 00~02 UTC에 USD/KRW 2.3~2.4가 3개 있어 제거했다. 같은 공급자를 쓰는 앱 수집기도 이런 값을 받을 수 있다(이번 분석 범위 밖).
  • 비용 — 수수료·펀딩비·슬리피지·환전 비용이 없다. F5는 gross다.
  • 호가 vs 종가 — 앱은 bookTicker, 분석은 체결 종가다. 일 단위 결론에는 영향이 작다고 본다 추정.
  • 앱 DB의 1초 데이터는 쓰지 않았다 — 로컬 DB에 쌓인 기간이 짧아 9년 검증에 못 쓴다.
  • "증명" 불가 — 통계 검정은 가설을 기각하거나 기각하지 못할 뿐이다. H1은 기각되지 않았고 H2·H3은 기각됐다.
