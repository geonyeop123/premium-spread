# 정리한 포지션의 확정 손익 — 체결 기준 (issue #130)

포지션 건에서 부분 정리나 전량 정리 사건이 생기면, 별도 Job이 빗썸·바이낸스 체결 내역을 읽어 실현 손익을 확정한다.
