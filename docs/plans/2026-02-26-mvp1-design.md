# MVP 1 설계 문서

> 작성일: 2026-02-26

## 1. 목표

김치 프리미엄 실시간 모니터링 + 수동 포지션 관리가 가능한 풀스택 웹 서비스를 단일 AWS 서버에 배포한다.

## 2. 범위

### 포함

| 영역 | 내용 |
|------|------|
| 백엔드 API | 회원 인증 보강, 회원별 포지션, 수익률 API, 실시간 데이터 전송 |
| 프론트엔드 | Next.js 웹 UI (로그인, 프리미엄 차트, 포지션 관리) |
| 차트 | 실시간 프리미엄 값 + 1분/1시간/1일 라인 차트 |
| 인프라 | 단일 EC2 + Docker Compose + 도메인 + HTTPS + CI/CD |

### 제외 (MVP 2+)

- 알림 (Telegram/Email)
- 자동매매 (Trading V3)
- 실계좌 연동 (Trading V2)
- 모바일 앱
- 주간 차트, OHLC 캔들, 환율 고정 옵션
- ECS/RDS/ElastiCache, 오토스케일링, Blue/Green 배포

## 3. 백엔드 변경

### 3-1. Position에 memberId 추가

- `position` 테이블에 `member_id BIGINT NOT NULL` FK 추가 (Flyway V8)
- Position 엔티티, Command, Criteria, API에 memberId 반영
- 로그인한 회원만 자기 포지션 CRUD 가능

### 3-2. API 인증 보호

SecurityConfig 수정:

- 공개 엔드포인트:
  - `POST /api/v1/members/register`
  - `POST /api/v1/members/login`
  - `GET /api/v1/premiums/**`
  - `GET /api/v1/tickers/**`
- 인증 필요:
  - `/api/v1/positions/**`
  - `GET /api/v1/members/me`
  - `POST /api/v1/members/logout`

### 3-3. 수익률 API

- `GET /api/v1/positions/summary` — 총 누적 수익률, 총 포지션 수, 수익/손실 비율
- `GET /api/v1/positions/history` — 닫힌 포지션 목록 (매도 이력)

### 3-4. 실시간 데이터 전송

프론트에서 실시간 프리미엄/가격 표시를 위한 데이터 전송 방식:
- SSE (Server-Sent Events) 또는 polling (5초 간격) 중 택 1
- 구현 시 트레이드오프 비교 후 결정

## 4. 프론트엔드

### 4-1. 기술 스택

- Next.js 14+ (App Router)
- TailwindCSS + shadcn/ui
- TradingView Lightweight Charts
- Axios/fetch

### 4-2. 페이지 구성

| 페이지 | 경로 | 설명 |
|--------|------|------|
| 대시보드 | `/` | 실시간 프리미엄/가격 + 차트 |
| 로그인 | `/login` | 이메일/비밀번호 로그인 |
| 회원가입 | `/register` | 이메일/비밀번호 가입 |
| 포지션 목록 | `/positions` | 내 포지션 목록 + 매수/매도 폼 |
| 포지션 상세 | `/positions/[id]` | 포지션 상세 + PnL |

## 5. 인프라 & 배포

### 5-1. 도메인

- 도메인 등록 (가비아, Namecheap, Route 53 등)
- DNS A 레코드 → EC2 Elastic IP
- Let's Encrypt + certbot 자동 갱신

### 5-2. 서버 구성

```
EC2 (t3.medium, 2 vCPU, 4GB RAM) + Elastic IP
├── Docker Compose
│   ├── nginx (리버스 프록시 + SSL 종료)
│   │   ├── / → web (:3000)
│   │   └── /api → api (:8080)
│   ├── api (Spring Boot, Port 8080)
│   ├── batch (Spring Boot, Port 8081)
│   ├── web (Next.js, Port 3000)
│   ├── mysql (Port 3306)
│   └── redis (Port 6379)
```

### 5-3. CI/CD

- GitHub Actions
- `feature/premium` → `main` 머지 시 자동 배포
- SSH로 EC2 접속 → docker compose pull & up

### 5-4. 예상 비용

| 항목 | 월 비용 |
|------|--------|
| EC2 t3.medium | ~$30 |
| Elastic IP | 무료 (인스턴스 연결 시) |
| 도메인 | ~$10~15/년 |
| **합계** | **~$30/월** |

## 6. 구현 순서

| Phase | 작업 | 설명 |
|-------|------|------|
| **Phase 1** | Position memberId + API 인증 보호 | Position에 회원 소유 개념 추가, SecurityConfig 인증 보호 |
| **Phase 2** | 수익률 API + 포지션 이력 | 닫힌 포지션 목록, 누적 수익률 API |
| **Phase 3** | 실시간 데이터 전송 | SSE or polling으로 프리미엄/가격 실시간 전달 |
| **Phase 4** | Next.js 프로젝트 + 인증 UI | 프로젝트 구성, 로그인/회원가입 페이지 |
| **Phase 5** | 대시보드 + 차트 | 실시간 프리미엄 표시, TradingView 차트 |
| **Phase 6** | 포지션 관리 UI | 매수/매도/PnL/이력 페이지 |
| **Phase 7** | AWS 인프라 | EC2 + 도메인 + SSL + Docker Compose |
| **Phase 8** | CI/CD + 최종 배포 | GitHub Actions 파이프라인, 운영 배포 |
